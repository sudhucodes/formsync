## Basic Usage with React / Next.js

FormSync provides a clean **React Hook** API using the `newFormSync` hook.
This allows you to easily handle form submissions, loading states, and callbacks without manual state management.

### Example

```tsx
'use client'
import { newFormSync } from "formsync";
import { toast } from "react-toast-msg";

export default function Example() {
    const { submit, isLoading } = newFormSync({
        formId: "YOUR_FORM_ID",
        onSuccess: (res) => toast.success(res.message),
        onError: (err) => toast.error(err.message),
    });

    return (
        <main>
            <form onSubmit={submit}>
                <input
                    type="text"
                    name="name"
                    placeholder="Name"
                    required
                />
                <button type="submit" disabled={isLoading}>
                    {isLoading ? "Submitting..." : "Submit"}
                </button>
            </form>
        </main>
    );
}
```

## Handling Form States

### Success Callback

The `onSuccess` callback is triggered when the form submission is successful.

```tsx
onSuccess={(res) => {
    console.log(res.message);
}}
```

### Error Callback

The `onError` callback is triggered if the submission fails.

```tsx
onError={(err) => {
    console.error(err.message);
}}
```

Both callbacks receive a structured response object from FormSync.

### `newFormSync` Options

| Prop | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `formId` | `string` | `true` | Your unique Form ID from the dashboard. |
| `onSuccess` | `function` | `false` | Callback triggered on successful submission. |
| `onError` | `function` | `false` | Callback triggered when submission fails. |
| `baseURL` | `string` | `false` | Optional custom API base URL. |

## Loading State

The `newFormSync` hook returns an `isLoading` boolean state. Use this to disable your submit button or show a loading spinner.

```tsx
const { submit, isLoading } = newFormSync({ ... });

// ...

<button type="submit" disabled={isLoading}>
    {isLoading ? "Processing..." : "Submit"}
</button>
```

## Spam Protection

FormSync automatically handles spam protection. There is no need to manually add honeypot fields to your form when using the `newFormSync` hook.
