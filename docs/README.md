# Contributing to Formsync Documentation

Thank you for your interest in improving Formsync! This directory contains the source content for our official documentation.

## How to Contribute

If you find any typos, outdated information, or want to add new content:

1.  **Find the file**: All documentation content is located in the [`content`](./content) directory.
2.  **Make your changes**: Edit the markdown files directly.
3.  **Submit a PR**: Open a Pull Request with your changes.

## Internal Tooling

We use **[Docstra](https://docstra.sudhucodes.com)** internally to manage and serve our documentation. If you are modifying the structure or adding new sections, please ensure you follow the existing folder hierarchy within the `content` directory.

---

For major changes or suggestions, feel free to open an issue in the main repository.
